From pair to pull request

Order matters here — this is the real path from a cold install to a merged branch.

  1. 1

    Add a provider key

    Paste an Anthropic, OpenAI, or custom base URL + key. Tap refresh to load models.

  2. 2

    Pair the desktop server

    Run the companion on your Mac. Enter the address and six-digit code — or scan the QR.

  3. 3

    Pick a repo and describe the task

    The agent clones, runs bash and file tools, and streams tool cards and diffs to the phone.

  4. 4

    Open the pull request

    Review the session, then create the PR from the same thread when you’re ready.

Built like the desktop you already trust

Same cool blue-grey shell as the Electron companion — dark, quiet, focused on the work.

Native SwiftUI client

Composer, model picker, environment & repo chips, coding session with tool cards and diffs — not a WebView wrapper.

Desktop agent

WebSocket pairing, git clone, bash, file edits, PR open. Your machine does the heavy lifting.

Keychain storage

Provider keys and tokens never write to disk on the server. Session-scoped handoff only.

Open protocol

App ↔ server messages are documented. Fork it, extend tools, or point at your own stack.

Ship from the couch.

Clone the repo, run the desktop server, drop in a key, and pair your phone.
